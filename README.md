# Умная колонка Kamish

Автономная умная колонка на базе микрокомпьютера архитектуры ARM64, работающая под управлением **Kamish OS Linux (собственной встроенной ОС на базе Buildroot ARM64)**.

Проект спроектирован по принципу **Offline-First**: все базовые функции (будильники, напоминания, индикация статуса, синтез речи) полностью функциональны без доступа к интернету и облачному ИИ.

## 🌟 Возможности и функции

| Категория | Возможности | Технологии и реализация |
|---|---|---|
| **Музыка** | Потоковое и локальное воспроизведение треков, плейлистов и рекомендаций | YouTube Music, Lavalink v4 / `yt-dlp` (`--js-runtimes node`), локальная фонотека (FLAC, MP3, WAV), headless MPV через UNIX IPC сокет (`/tmp/mpv-kamish.sock`), персональные рекомендации YouTube Music |
| **Радио** | Воспроизведение интернет-радиостанций | Каталог онлайн-станций, потоковое вещание Icecast и HLS через MPV |
| **Умный дом** | Будильники, напоминания, таймеры с поддержкой часовых поясов и повторений | Автономный движок планировщика (`chrono-tz`), синтез звуковых тонов гонга без сети, поддержка действий snooze / dismiss |
| **ИИ** | Интеллектуальный диалог и голосовое управление устройством на естественном языке | Antigravity CLI (`agy`) с резервным офлайн `MockAiClient`; строго изолированный реестр из 14 инструментов (Tool Registry) без прямого доступа модели к Shell и файловой системе |
| **Голос (STT / TTS)** | Голосовой интерфейс, распознавание и синтез речи | 100% локальная обработка (облачные сервисы запрещены): VAD на чистом Rust (RMS + ZCR), wake-word споттер («ассистент», «колонка», «слушай»), распознавание речи Vosk, нейросетевой синтез речи Piper TTS |
| **Bluetooth** | Беспроводное воспроизведение звука (колонка для внешних устройств) | Режим Bluetooth A2DP Sink на базе BlueZ / BlueALSA со смартфонов, планшетов и ПК; управление сопряжением и обнаружением |
| **Сеть и связь** | Управление Wi-Fi, точка первичной настройки, защищённый туннель | NetworkManager (`nmcli`), точка доступа `kamish-setup` (192.168.4.1) для первичной настройки без экрана, клиент Happ / VLESS Reality для обхода блокировок с маскированием секретов |
| **Защита акустики и железа** | Защита динамиков GT-112, мониторинг температуры процессора | Программный лимитер Safe Volume Ceiling (85%) для защиты усилителя GT-112 от клиппинга и перегрева, мониторинг температуры SoC (`/sys/class/thermal/`) с предупреждением о троттлинге ($\ge 80^\circ\text{C}$) |
| **Веб-панель управления** | Наглядный веб-интерфейс и мастер первоначальной настройки | React 19, TypeScript, Tailwind CSS (стандарт `kill-ai-slop`), мастер первоначальной настройки (Setup Wizard), аутентификация Argon2id, WebSocket-шина событий реального времени (`/api/v1/events`) |

## 🚀 Быстрый запуск для разработки (Linux x86_64)

### Требования
- **Rust**: 1.75+ (`rustup default stable`)
- **Node.js**: 18+ и `npm`
- **SQLite 3**
- **MPV** (опционально, при отсутствии переходит на mock)

### 1. Сборка SPA-интерфейса
```bash
cd crates/kamish-web/frontend
npm install
npm run build
cd ../../..
```
Статические файлы автоматически соберутся в `crates/kamish-web/frontend/dist/`.

### 2. Запуск тестов
```bash
cargo test --workspace
```
> [!NOTE]
> Все интеграционные и модульные тесты выполняются бесшумно. Проверка наличия тестового раннера автоматически глушит вывод звука (`set_audio_muted(true)`).

### 3. Запуск сервиса
```bash
cargo run -p kamish-web
```
Сервис запустится по адресу `http://0.0.0.0:8080`.
Откройте браузер по адресу `http://localhost:8080/` (или `http://kamish.local:8080`).

## 📦 Развёртывание на целевом устройстве (ARM64)

Kamish OS работает под управлением специализированного легковесного образа **Kamish Linux**, собираемого с помощью **Buildroot**:

1. **Сборка прошивки и OTA-бандла**:
   Сборка выполняется в изолированном Docker-контейнере или хост-системе:
   ```bash
   cd firmware
   ./scripts/build-firmware.sh
   ```
   Готовый образ `sdcard.img` и OTA-пакеты будут сформированы в `firmware/output/images/`.

2. **Запись образа**:
   Запишите скомпилированный образ `sdcard.img` на накопитель (microSD / eMMC) с помощью `dd` или BalenaEtcher:
   ```bash
   sudo dd if=firmware/output/images/sdcard.img of=/dev/sdX bs=4M status=progress conv=fsync
   ```

3. **Подключение периферии**:
   - Подключите Seeed ReSpeaker XVF3800 к USB-порту.
   - Подключите акустику GT-112 к аналоговому аудиовыходу (разъём 3.5мм или линейные пины).
   - Вставьте карту памяти и подайте питание (рекомендуется БП 5V / 3A).

4. **Первичная настройка (Setup AP)**:
   При первом старте колонка поднимает точку доступа Wi-Fi `kamish-setup` (192.168.4.1:8080). Перейдите в браузере по адресу `http://192.168.4.1:8080` и завершите мастер настройки.

5. **Проверка железа**:
   ```bash
   ./deploy/scripts/hardware_check.sh
   # С воспроизведением тестового звукового тона:
   ./deploy/scripts/hardware_check.sh --test-audio
   ```
