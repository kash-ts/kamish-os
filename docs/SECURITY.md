# Политика безопасности Smart Speaker

## Основные принципы защиты

1. **Изоляция ИИ**:
   - AI Orchestrator запускается в изолированном контексте и общается с бэкендом через структурированный протокол (JSON).
   - Antigravity CLI не имеет прямого доступа к шеллу (`/bin/sh`, `/bin/bash`), управлению демонами или произвольному чтению файлов.
   - Любое действие выполняется исключительно через зарегистрированные инструменты в `Tool Registry` со строгой типизацией параметров.

2. **Защита конфиденциальных данных**:
   - Пароли Wi-Fi, токены авторизации, cookies музыкальных сервисов и приватные ключи VLESS / Happ не выводятся в логах (`tracing`).
   - Пароли сетей маскируются при передаче в API.
   - Секретные конфигурации отделены от обычной базы данных.

3. **Сетевая безопасность**:
   - Панель управления и API доступны только в локальной сети устройства (LAN).
   - Точка первичной настройки (Setup AP) выключается после успешного подключения к домашней сети.
   - Защита от переполнения буфера и атак внедрения команд за счет типобезопасности Rust.

4. **Идемпотентность и валидация**:
   - Все входящие HTTP-запросы валидируются через парсеры Serde.
   - Исключено выполнение команд, сформированных прямой конкатенацией пользовательских строк.
