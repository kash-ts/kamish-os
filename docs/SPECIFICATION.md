# Спецификация и технические требования (SPECIFICATION.md)

Документ описывает согласованные технические характеристики, аппаратные ограничения, интерфейсные соглашения и показатели SLA для автономной умной колонки **Smart Speaker**.

---

## 1. Аппаратная платформа и окружение

| Компонент | Спецификация | Требование / Ограничение |
|---|---|---|
| **Вычислительный модуль** | Orange Pi Zero 3 | SoC Allwinner H618 (Quad-Core Cortex-A53 @ 1.5 GHz) |
| **Оперативная память** | 4 GB LPDDR4 | Лимит потребления памяти сервисом бэкенда: $\le 150\text{ MB}$ RSS |
| **Хранилище** | MicroSD Class 10 / UHS-I (от 32 GB) | SQLite в режиме WAL, ротация логов (max 50 MB) |
| **ОС** | Armbian Linux (Debian 12 Bookworm Minimal) | Ядро Linux $\ge 6.1$ ARM64, systemd |
| **Аудиопроцессор (Вход)** | Seeed ReSpeaker XVF3800 | 4-микрофонный массив, USB Audio Class, аппаратный AEC/Beamforming |
| **Формат аудиовхода** | 16 кГц, 16 бит PCM, Mono | Задержка буферизации кадра $\le 20\text{ мс}$ (320 сэмплов) |
| **Акустика (Выход)** | GT-112 (модифицированная) | Встроенный усилитель D-класса, 2 динамика, подключение Line-Out ALSA |
| **Лимит громкости** | Safe Volume Ceiling: **85%** | Защита от клиппинга усилителя и термического разрушения катушек |
| **Питание** | 5V / 3A DC через USB Type-C | Пиковое потребление системы не должно превышать 12 Вт |
| **Температурный режим** | Allwinner H618 SoC | Warning: $\ge 70^\circ\text{C}$, Throttling: $\ge 80^\circ\text{C}$, Critical: $90^\circ\text{C}$ |

## 2. Архитектурные требования и инварианты

### 2.1. Offline-First (Автономность)
1. Базовые функции должны работать на 100% без подключения к глобальному интернету:
   - Локальные будильники и напоминания со звуковым оповещением.
   - Локальная база данных SQLite.
   - Воспроизведение сохранённых аудиофайлов и локальных звуковых сигналов через MPV.
   - Веб-интерфейс настройки и управления через локальную сеть или точку доступа Setup AP.
   - Офлайн-распознавание ключевого слова (вейкворд) и офлайн-генератор системных голосовых тонов.
2. Отсутствие внешних сервисов (AI API, YouTube Music, облачный TTS) не должно блокировать запуск или работу остальных модулей.

### 2.2. Безопасность и изоляция секретов
1. **Изоляция AI-оркестратора**:
   - Языковая модель (Antigravity CLI / LLM) не имеет прямого доступа к Shell, файловой системе хоста или переменным окружения.
   - Взаимодействие осуществляется исключительно через строго типизированный реестр из **14 инструментов** (*Tool Registry*).
2. **Защита секретных данных**:
   - Пароли Wi-Fi сетей (WPA2/WPA3 PSK), токены авторизации, приватные ключи VLESS и cookies музыкальных сервисов запрещено логировать (в stdout/stderr/syslog) и возвращать в открытом виде через REST API или WebSocket.
   - В API отдаётся только маскированный статус (`is_configured: true`, `has_password: true`).

### 2.3. Сетевой стек
1. **Первичная настройка (Setup AP)**:
   - При отсутствии известной Wi-Fi сети колонка поднимает локальную точку доступа `SmartSpeaker-Setup` (IP-адрес: `192.168.4.1`, без пароля или со стандартным паролем).
   - Доступен веб-интерфейс мастера первой настройки.
2. **Рабочий режим**:
   - Подключение по Wi-Fi (2.4/5 GHz) через NetworkManager (`nmcli`).
   - Доступность по mDNS: `http://<hostname>.local:8080`.
3. **Безопасный туннель (VLESS / Reality)**:
   - Маршрутизация трафика музыкальных сервисов при блокировках.
   - Автоматический сбор метрик трафика (RX/TX байты) и индикация статуса пинга.

## 3. Показатели производительности (SLA)

| Параметр | Целевое значение | Максимально допустимое |
|---|---|---|
| Время холодного старта бэкенда | $\le 1.0\text{ с}$ | $2.5\text{ с}$ |
| Отклик REST API на локальные запросы | $\le 15\text{ мс}$ | $50\text{ мс}$ |
| Задержка срабатывания будильника/напоминания | $\le 100\text{ мс}$ | $500\text{ мс}$ |
| Задержка VAD (детекция начала/конца речи) | $\le 20\text{ мс}$ | $50\text{ мс}$ |
| Задержка детекции вейкворда | $\le 100\text{ мс}$ | $300\text{ мс}$ |
| Задержка реакции плеера (Play/Pause/Volume) | $\le 50\text{ мс}$ | $150\text{ мс}$ |
| Потребление RAM бэкендом (idle) | $\approx 25\text{ MB}$ | $60\text{ MB}$ |
| Время выполнения полного набора тестов (`cargo test`) | $\le 3\text{ с}$ | $10\text{ с}$ |

## 4. Спецификация аудио и лимитера громкости

1. **Безопасный потолок громкости (Safe Volume Ceiling)**:
   - Программный максимум громкости зафиксирован на уровне **85%** от шкалы ALSA.
   - Любой запрос на установку громкости $\ge 85\%$ автоматически ограничивается значением 85%.
   - Реализована функция аварийного глушения звука (`mute`) и возврата к предыдущему уровню.
2. **Маршрутизация звука**:
   - `LineOut` — основной выход на динамики GT-112 (ALSA PCM `hw:0,0` или `default`).
   - `Bluetooth` — вывод на беспроводные наушники / стороннюю колонку через BlueALSA.
   - `Jack` — аудиовыход 3.5 мм Orange Pi.
3. **Голосовой движок (Speech Pipeline)**:
   - VAD: комбинированный алгоритм RMS (энергия сигнала) + ZCR (частота перехода через ноль) с настраиваемым порогом и временем удержания (*hangover* 300 мс).
   - Wakeword Spotter: локальный споттер с поддержкой симуляции и потокового аудио.
   - TTS: модульный синтез речи с автономным генератором WAV-тонов для системных оповещений без внешних библиотек.
